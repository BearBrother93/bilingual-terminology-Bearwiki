# 维基熊 · 游戏英语 V1.0.0（纯文字网页）

## 页面定位
- 主栏目：游戏英语
- 首期专题：原神英语趣谈
- 正式词条：67 条
- 六个专题分辑
- 参考链接：44 条（原稿分辑来源范围，尚未逐条映射到词条）
- 图片：不使用图片，不加载图片资源

## 上传方式
将压缩包内的整个 `game-english` 文件夹上传至 GitHub 仓库：

`entertainment/game-english/`

部署后页面地址为：

`https://<你的GitHub用户名>.github.io/<仓库名>/entertainment/game-english/`

不要把 `data` 文件夹拆开，也不要改变 `data/chapters/` 中的文件名。

## 需要在娱乐入口添加链接
在 `entertainment/index.html`（如果你的仓库娱乐入口文件确实位于此路径）增加一个普通链接：

`<a href="./game-english/">游戏英语 · 原神英语趣谈</a>`

如果你的娱乐入口实际位置不同，请按实际相对路径调整。此次没有改动网站根目录首页或现有娱乐页，以免覆盖你当前线上版本。

## 文件结构
- `index.html`：页面结构
- `style.css`：极简响应式样式
- `app.js`：检索、导航和词条渲染
- `data/navigation.json`：项目介绍、免责声明、收录范围、六辑目录
- `data/references.json`：44 条参考链接及来源范围说明
- `data/chapters/*.json`：六辑、67 个词条
- `data/manifest.json`：数据版本信息

## 已实现功能
- 中文名、英文名及词条正文关键词搜索
- 六辑导航及全部词条浏览
- 词条详情显示：词源与构词、英语知识、文化与译名、证据备注
- 显示同辑参考来源，并明确说明尚未逐条映射到具体词条
- 桌面端双栏布局、手机端自适应
- 不调用机器翻译或 AI 接口
- 纯文字，无图片资源

## 内容边界
本网页以 Word 母版和已完成的 V1.0.1-QA JSON 为依据。67 个词条六项核心文本与 Word 原稿逐字一致。此项是完整性核对，不等同于词源事实、最新官方名称或来源有效性的独立核验。证据等级尚未逐条完成编辑分级，因此网页明确显示“证据等级待编辑”。

本专题由 AI 辅助整理并经人工编辑，不是 HoYoverse 官方资料或认证内容。欢迎读者提供词条编号、具体修改建议和可核查来源。
