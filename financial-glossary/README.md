# 译典 · GitHub Pages 准备版

这是现有术语库样站的静态部署包。当前收录《财经术语英中对照（审校去重版）》主表的 9,150 条词条，提供英文 A–Z 索引、双语搜索、分批载入与单条链接。原表的 469 条重复记录不在前台显示。页面不包含个人资料，也没有把原审校表的重复记录放到前台。

## 发布

1. 将此目录全部文件放入新 GitHub 仓库的根目录，包括 `.nojekyll` 和 `.github/ISSUE_TEMPLATE/term-feedback.yml`。
2. 在仓库 Settings → Pages 中选择从 `main` 分支根目录部署。部署前确认仓库公开展示的内容适合公开。
3. 当前站内尚未启用互动入口。仓库建立后可将 Issue 工单与 Discussions 链接接到页面；请勿把公开工单当作私信。
4. 按需启用仓库 Issues（纠错工单）和 Discussions（公开交流及反应）。

## 互动边界

- 工单和 Discussions 均为公开内容，访客通常需要 GitHub 账户才能发言；它们不承担私信功能。
- 私人咨询需另接安全的表单服务、邮件或后台。切勿把访问令牌、邮箱密码放进静态页面；没有确认接收地址前不显示伪装可提交的表单。
- “点赞”可借用 Discussions 的表情反应；若要在术语卡片上展示真实计数，需接入可靠的数据接口。若“赞赏”指付款或打赏，应另行选定支付渠道和收款主体。
- GitHub Pages 的部署不等于中国大陆网络必然可直连。上线后须从实际使用地、运营商及移动网络测试首页、CSS/JS、出处链接和 GitHub 互动入口。必要时迁移到可稳定访问的托管与域名。

## 后续数据结构

正式词条建议包括：原文、译文、语言方向、领域分支、释义、适用地区／准则版本、双语例句、出处链接与段落／页码、关联术语、核定日期。仅公开已确认项；审校重复及内部工单状态不在主卡片展示。
