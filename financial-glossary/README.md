# 维基熊 BearWiki · 财经术语库

**词有所据，译有所依。**  
可溯源的双语术语与知识库。

BearWiki 是一个持续建设中的中英双语专业术语与知识平台。本分库收录财经、会计及金融相关英中术语，支持英文 A–Z 索引、中文与英文检索、单条词目链接及参考资料展示。

## 当前数据

- 术语：9,150 条
- 已关联参考资料的词条：以 `references.json` 实际记录为准
- 术语数据：`terms.json`
- 参考文献数据：`references.json`
- 页面逻辑：`app.js`
- 页面与样式：`index.html`
- 品牌图标：`bearwiki-mark.svg`

以上数据会随着后续编录和核查持续更新。

## 发布方式

本目录位于仓库的 `financial-glossary/` 子目录。若 GitHub Pages 从 `main` 分支的仓库根目录发布，可通过对应子路径访问本分库：

`/financial-glossary/`

网站依赖相对路径加载 `terms.json`、`references.json`、`app.js` 和 `bearwiki-mark.svg`。移动文件或调整目录时，须同步检查引用路径。

## 文献与证据原则

- 区分术语本身、专业释义、翻译判断与参考资料。
- 参考资料的存在不自动代表其已充分支持中文译名；应结合来源类型、具体内容及适用语境判断。
- 不编造来源、引文、页码或核验状态。
- 尚未找到或尚未核实的资料应明确标记，不以推测填补。
- 网站内容持续补充与校订，正式发布前应检查数据关联及链接有效性。

## 版权与公开范围

仅发布适合公开的术语数据、说明及参考资料。不得将未发表译稿、内部审校意见、受保密义务约束的材料或未经许可的受版权保护内容上传至公开仓库。

## 更新建议

日常更新优先修改术语与参考文献数据文件。只有在页面功能或视觉样式发生变化时，才更新 `app.js`、`index.html` 或品牌图标。每次提交应填写清晰的 Git 提交说明，并保留可回退的历史版本。
