| 场景 | 新页面会话的结果 |

预览浏览器的空白页导航约 52 ms，单个本地资源请求本次观察约 3–47 ms。这里是预览环境观测，并受 HTTP 缓存影响，不能当作公网冷启动、移动网络或中国大陆速度。正文总字节来自实际 JSON 文本计数，非浏览器传输量；部分浏览器资源 transferSize=300 反映缓存协商，不能用它宣称词库只有 300 字节。

## 加载策略

- 初始空白页不请求 catalog 或词库；开始输入后才加载候选需要的方向索引。
- 依据首尾键定位索引页；不下载全词库，不猜原始哈希。
- 精确匹配只加载相关数据页；大量反查结果每次 20 条，最多 4 个数据页并发。
- 前缀每次 40 个候选，可持续展开，不静默丢弃其余结果。
- 相同请求复用 Promise；JSON 使用约 8 MiB 文本预算的会话 LRU 缓存。此预算不是 JavaScript 堆内存硬上限，解析后对象会增加内存开销。
- 版本化数据路径隔离浏览器旧缓存；catalog 使用 no-cache 协商。未来更换代码应同步提高脚本 / 样式版本号。
- 页面不调用 Google Fonts、CDN、机器翻译或付费接口。只有用户选择在线英英 / 音频 / 外部链接才接触对应外部服务。
