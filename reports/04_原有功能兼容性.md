# 原有功能兼容性检查

## 保留和改善

| 原功能 / 约束 | 结果 |
|---|---|
| dictionary/ 目录入口 | 保留 |
| 旧 ?q=charge | 实测直接查询英英，返回 29 个义项 |
| 原主页 GET 表单，action=./dictionary/、name=q | 未修改原主页实测成功 |
| 英文定义、词性、例句、音标、音频 | 保留真实 API 数据；没有数据时不生成 |
| 词条概览 | 保留计数，新增关闭 / 展开 |
| 外部词典 | 保留外部跳转；不复制商业词典内容 |
| 机器翻译 / 付费 API | 未调用 |
| 英英数据截断 | 移除旧代码的前 5 词条、12 组、每组 40 义项限制，展示全部返回内容 |
| 默认英文行为 | 无方向参数时，英文仍查在线英英，中文改查本地汉英 |
| GitHub Pages 项目子路径 | 实际在同名子路径测试成功，无写死域名或根路径 fetch |

原网站除 dictionary/ 外的 30 个文件逐个字节比较，改动数为 0，包括财经、电力、知识专题和娱乐栏目以及原主站 index.html。compatibility_checks.json 保存结果。

## 单独提供的主站更新

optional-home/index.html 是可选替换文件，与原主页相比只更新词典卡片的英文小标题、版本与介绍、搜索标签、占位词、AI 初步复核说明。没有覆盖其他栏目、修改其链接、数据或功能。GET action 与 q 参数不变。

旧首页仍能使用新词典，因此不替换主站 index.html 也能上线；但旧文字声称“中文解释为第三方自动参考译文”，与本次实况不符，建议使用单独提供的更新版。新版已在 /bilingual-terminology-Bearwiki/ 子路径点击提交“苹果”实测成功。

新参数：dir=auto/zh-en/en-zh/en-en；match=auto/exact/prefix。无参数保持兼容。日语方向没有对应输入数据，未加入可点击却无数据的选项。
