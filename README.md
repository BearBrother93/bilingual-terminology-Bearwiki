# 维基熊 BearWiki

**词有所据，译有所依。**

公开的双语专业术语与知识空间，包含财经术语库、筹备中的历史术语知识库与独立创作展示。

## 网站栏目

- `index.html`：网站统一首页和导航。
- `financial-glossary/`：财经英中术语检索，保留原有 `terms.json` 和 `references.json`。
- `entertainment/horizon-riders/index.html`：极境飞驰 Horizon Riders V1.0，完整独立 HTML（六条赛道、六首音乐）。
- `assets/`：全站共用 Logo。

## 发布方法

在 GitHub 仓库根目录上传以上目录与文件，GitHub Pages 选择 `Deploy from a branch`，分支 `main`，目录 `/(root)`。不要将 ZIP 直接作为附件上传；应解压后上传文件，并保留相对目录结构。

若只更新此次整合内容，使用 `BearWiki_Games_Integration_changes_only.zip`，不覆盖术语 JSON。

## 权利与数据

仅向公开仓库上传获准公开的内容；不得上传未发表译稿或受保密要求约束的资料。财经术语库文献来源仍在持续校订，公开显示不等于已逐条核验。

### 《极境飞驰》说明

游戏页面及六首原创配乐使用用户提供的 V1.0 最终整合 HTML。整合过程只向游戏菜单添加了返回维基熊的链接及可折叠说明，**内嵌的游戏 JavaScript、音乐数据、赛道、比赛逻辑未修改**。
